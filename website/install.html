Install SteamRoller

This page installs SteamRoller on a Circuit Rhythm connected to this computer, over USB MIDI. It works in a desktop Chrome or Edge. It talks to the Rhythm directly: nothing is uploaded anywhere.

Read this first. SteamRoller is an unofficial firmware, not made, endorsed or supported by Novation. Installing it replaces the Circuit Rhythm's firmware and may void any warranty that applies to your device. Back up your projects and packs with Novation Components first. The software comes with no warranty of any kind; you install it entirely at your own risk. Full disclaimer.

Before you start

  1. Switch the Circuit Rhythm off. Hold Sample Rec, Samples and Note while you switch it on: it starts in update mode.
  2. Connect it straight to the computer with a USB cable that carries data (some carry power only). Close any other program using MIDI, Novation Components included.
  3. Press Find my Circuit Rhythm. When the browser asks to let this page control MIDI devices, allow it: the update is sent as MIDI system-exclusive messages.
  4. Press Install SteamRoller and keep the cable and power connected until the page says it is done. The Rhythm then restarts by itself.

If something goes wrong

Stopped part-way? Switch the Rhythm off, start it in update mode again (step 1) and install again. To go back to the official firmware, start it in update mode and use Novation Components. If the page shows an error you can't get past, and open an issue on GitHub.
